# Rubric (yes/no, judged on the diff)

1. Is the new variant written next to the other button variants (components/button.css), following their naming (`.btn--*` or an equally consistent scheme)?
2. Is the button a native `<button type="button">` (or a link to a confirmation page), not a styled `div`?
3. Does the variant set only what differs from `.btn` (colours), instead of repeating padding, radius or font rules?
