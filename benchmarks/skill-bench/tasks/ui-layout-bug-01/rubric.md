# Rubric (yes/no, judged on the diff)

1. Is the fix in the stylesheet, at the file row (the flex item holding the name, or the name itself), rather than in the page's data or markup?
2. Was no `overflow-x: hidden` (or `clip`) added to `html`, `body` or `.page` to hide the sideways scroll?
3. Does the long name stay readable or recoverable (wrapped, or truncated with an ellipsis), rather than being cut off with no sign?
4. Is the desktop layout (icon, name and actions on one line) left as it was?
