# The report of a part

Step 8 of `SKILL.md` sends you here. `<part folder>` is the part's folder (the phase folder when the plan has no subphases). You write the report yourself: it is the facts of the run and of the checks, which the commands print, so no agent writes it and no file keeps it. A session that is cut redoes this from the same commands.

1. **Gather.** For each run `<R>` of the part that carries a review, oldest first (the run of step 5 and each `--fix` run of step 6, never a run that only reverted: it has no review; on a resume, the part's lines of `fwx wave list`, which prints the oldest first, without the revert-only ones), read `fwx wave --run <R> --json`: what the review found in `findings` (`reported`, `fix`, `fixed`, `consider` and `note`, `dismissed`), what it checked in `criteria`, `gaps` and `tried`, the `outside` items of the executors' reports, and the reviewer's large items in `findings.outside`: neither holds a Linear key, step 5 files them. With no run in sight, the report claims nothing about the review. Then read the last `evidence` row of the part's `audit.tsv`: `grep -P '\tevidence\t' <part folder>/audit.tsv | tail -1` (its columns are `date`, `kind`, `sha`, `detail`, `rc`; `detail` holds the commands and their exit codes). With no evidence row the checks left none: tell the owner and stop, because a report with no evidence is a claim.
2. **Fill the template.** Copy `${CLAUDE_PLUGIN_ROOT}/templates/phase/report.md` into your answer and fill each section from what step 1 printed, never from memory of what an agent said: Goal from `context.md`, Done from the plan's tasks and the run's `findings` and `criteria`, Assumptions taken without asking from the choices you made yourself (rule 6) and from the rows of the phase's `decisions.tsv` with support `agent-assumption` that no later row supersedes (a resume or the close has no memory of them), Outside from `outside` and `findings.outside`, each with the Linear key of its `filed: <where> - <KEY>` entry in the `--why` of the part's stage rows (step 5 writes it: `grep -P '\tstage\t' <part folder>/audit.tsv`), else `none filed`, Evidence the commit `<sha>`, the command and its exit code of the evidence row, PR `not opened yet` before the close. A walk that did not finish is said in Evidence. At most about 40 lines.
3. **Paste it.** Give the filled template to the owner as your message, whole, before you ask anything. Nothing is saved: the close writes the pull request body from the same template (step 1 of `closing.md`).

Then continue step 8 after the line that sent you here.
