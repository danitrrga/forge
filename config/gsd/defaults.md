Why `defaults.json` sets what it sets (a sibling file because GSD copies every key of the file into each new project's `.planning/config.json`, so a `_doc` key inside it would land in every project's config).

`~/.gsd/defaults.json` is a copy of `config/gsd/defaults.json`, made by `scripts/sync/sync_gsd_runtime.py --apply`. GSD reads it in `buildNewProjectConfig` (`gsd-core/bin/lib/config.cjs`) when it creates a project's `.planning/config.json`, merged under the user's choices; a nested `workflow` object is accepted.

A copy and not a link because GSD writes that file (read in the installed GSD): the settings workflow's "save as global defaults" (`workflows/settings.md:393-399`) has the agent write `~/.gsd/defaults.json`, which through a link would overwrite forge's tracked file; `config.cjs:148` also rewrites it, by temp file and rename, but only to migrate a deprecated `depth` key. A real file there that differs from forge's is the user's choice (the settings workflow writes it on purpose): it is left alone and reported as one plain line, with no `!`, exit 0 and 0 changes. Delete it to let the next sync copy forge's, or move what it holds into `config/gsd/defaults.json`. The same applies after forge edits this file: every existing copy then differs, and stays as it is, until it is deleted.

forge sets no GSD default (2026-10-23, Daniel: "give gsd-core all the functionalities, no cap"): `defaults.json` is an empty object, so a new project gets GSD's own values, `workflow.ui_phase` and `workflow.ui_safety_gate` on included. Until that day the file set both to false, because plan-phase's step 5.6 gate (the UI design contract, `UI-SPEC.md`) fires on nearly every frontend phase and design-taste, impeccable and ui-typography already cover that ground; the cost of the change is that gate on every frontend plan, and a project that does not want it sets `workflow.ui_phase false` in its own `.planning/config.json` (`/gsd-settings`). The file stays, empty, so a user's own defaults (the settings workflow writes `~/.gsd/defaults.json`) keep working, and `sync_gsd_runtime.py` replaces a `~/.gsd/defaults.json` that still holds forge's earlier text (`FORMER_DEFAULTS`) and nothing else.
